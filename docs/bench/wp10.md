# WP10 bench session: studio housekeeping

The checklist is §6 of the WP10 brief (Plane page "16 — WP10 brief").
Record the results in a comment on **LIVESTACK-58**. Steps 1 and 2 need an
installed studio with the tray; steps 3 and 4 work on a dev instance.

## Steps

| # | Do | Expect / record |
|---|---|---|
| 1 | Tray → right-click → **Sair**. Then Task Manager → Details, look for `pythonw.exe`. | The icon disappears within 2 s and no tray `pythonw.exe` is left. Before quitting, also note how many tray `pythonw.exe` were running (should be one, even after install + logon; two would mean the old duplicate-tray cause, ADR 0014 §1). |
| 2 | Playout setup → OBS: a wrong password. Save. Readiness → **Run checks**. Wait ≤ 5 s, hover the icon. Put the right password back, run the checks again. | Amber after the run; the tooltip says "verificação das HH:MM: 1 falha" (plus any warnings) at the run's local time. Green within 5 s of the second run finishing. |
| 3 | Dev instance with no Caddy (the gateway module on): `python -m baja_studio` and leave it for two minutes. Look at the console and the Logs page. | One `device offline: …` warning for the gateway and one "restarting worker in 1 s"; no line per retry. Start Caddy (or turn the gateway off and on): one INFO line "… recovered after N failures". |
| 4 | Cameras page → ⚙ (beside the camera's name). Then open `/settings/cameras`, and the home page's Cameras card. | The gear opens *Camera setup*. `/settings/cameras` shows only the JSON with a "⚙ Camera setup" link, no fields. The Cameras card's page links to *⚙ Camera setup*. |
